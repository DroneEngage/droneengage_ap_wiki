# DroneEngage Camera Module

<iframe width="560" height="315" src="https://www.youtube.com/embed/Q-OyRnisq8U" title="YouTube video player" frameborder="0" allow="accelerometer; autoplay; clipboard-write; encrypted-media; gyroscope; picture-in-picture; web-share" allowfullscreen></iframe>


DroneEngage provides comprehensive camera management capabilities, enabling simultaneous image capture, video recording, and video streaming across multiple cameras.

With proper configuration, the camera data connection can operate independently of the main connection, ensuring reliable and uninterrupted streaming.



<iframe width="560" height="315" src="https://www.youtube.com/embed/VgB98DvSreg" title="YouTube video player" frameborder="0" allow="accelerometer; autoplay; clipboard-write; encrypted-media; gyroscope; picture-in-picture; web-share" allowfullscreen></iframe>


Multiple boards can be connected within the same DroneEngage unit, with each board running its own de_camera module and connected to different cameras. For example, a Raspberry Pi 5 and an NVIDIA board can each be connected to separate cameras on the same drone.
